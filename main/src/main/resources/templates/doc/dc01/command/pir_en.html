Description

The module is used for detecting the movement of humans and animals. Currently, it only supports periodic reporting and trigger reporting, without a command issuance mode.

Example
type 0 indicates periodic reporting, 1 indicates trigger reporting.
triggerTimesTotal Total number of triggers since the device was powered on.
triggerTimesFromPreviousUpload Number of triggers since the last report.
stateKeepSeconds How many seconds the current state has been maintained.
pirStatus 1 indicates activity, 0 indicates no activity.

Returns normal
