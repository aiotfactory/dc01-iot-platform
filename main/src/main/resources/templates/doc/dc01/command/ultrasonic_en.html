Description

Ultrasonic distance measurement module.

Parameter Description
Parameter Description Required Type Bytes In/Out
operate Fixed value: 24 Yes Number 1 In
Example
Get current distance measurement:

operate=24

Response (normal):

totalMeasureTimes Total number of measurements since power-on.
historyMin, historyMax Minimum and maximum values measured since power-on, in millimeters (mm).
min, max, avg Minimum, maximum, and average values from this report, in millimeters (mm).
measureTimes Number of measurements included in this report.
values List of individual measurement values in this report, comma-separated, in millimeters (mm).
type Upload type:
- UPLOAD: Periodic automatic upload
- REQUEST: Upload triggered by cloud request
- TRIGGER: Upload triggered by condition
