说明

模块用于对目标热成像，热成像传感器一般是很昂贵的设备，本品采用性价比最高的传感器，支持32*24像素， 热成像不同于摄像头，摄像头是感知可见光，热成像是感知温度，可以理解为同时测32*24个点的温度值。

参数说明
参数 描述 必须 类型 字节 入出
operate 固定为23 是 数字 1 输入
例子
获取热成像数据:

operate=23

返回，正常

times 设备开机到现在累计上报次数。
maxCurrent，minCurrent，avgCurrent 本次上报像素中温度最高，最低和平均值，值为扩大10倍的结果，因此使用时除以10。
maxI，maxJ，minI，minJ 最大值和最小值像素的坐标。
maxHistory，minHistory，avgMaxHistory，avgMinHistory 设备开机以来，温度最高，最低，平均最高和平均最低值，值为扩大10倍的结果，因此使用时除以10。
pixels 本次上报具体的值，值为扩大10倍的结果，因此使用时除以10
