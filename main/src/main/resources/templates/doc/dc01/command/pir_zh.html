说明

模块用侦测人体和动物的移动，目前只有周期上报和触发上报，没有下发命令模式。

例子
type 0表示周期上报，1表示触发上报。
triggerTimesTotal 设备上电以来触发的总次数。
triggerTimesFromPreviousUpload 上一次上报后，触发的次数。
stateKeepSeconds 当前状态保持了多少秒。
pirStatus 1表示有活动，0表示无活动。
